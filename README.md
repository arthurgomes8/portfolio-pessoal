## 🛠️ Tecnologias e Ferramentas

As tecnologias utilizadas variam de acordo com cada projeto. Entre as principais estão:

- **HTML5** — estruturação de páginas web.
- **CSS3** — estilização, layouts e responsividade.
- **JavaScript** — lógica de programação e interatividade.
- **Python** — análise e manipulação de dados.
- **Pandas** — tratamento, organização e análise de dados.
- **Matplotlib** — criação de gráficos e visualizações.
- **Jupyter Notebook** — desenvolvimento e documentação de análises.
- **Git e GitHub** — versionamento e publicação de projetos.

## 🚀 Projetos em Destaque

### Desenvolvimento Web
- **Projeto de Vídeos:** incorporação de mídias e navegação entre páginas.
- **Projeto de Cordel:** apresentação de conteúdo com efeito parallax.
- **Projeto Android:** apresentação de conteúdo com imagens adaptáveis.
- **Projeto Redes Sociais:** interface interativa e utilização de iframes.
- **Projeto Login:** formulário e layout responsivo.
- **Projeto Álbum de Fotos:** organização de imagens com CSS Flexbox.

### Aplicações com JavaScript
- **To-Do List:** gerenciamento de tarefas com manipulação dinâmica do DOM e validação de entradas.
- **Jogo da Velha:** jogo interativo com controle de estado, gerenciamento de eventos e verificação das condições de vitória.

### Análise de Dados
- **Olist E-commerce:** análise exploratória de dados de um e-commerce brasileiro utilizando Python, Pandas e Matplotlib. O projeto investiga pedidos, clientes, produtos, pagamentos, entregas, avaliações e vendedores.

Para conhecer os detalhes, as tecnologias e os resultados de cada trabalho, visite o portfólio ou acesse os repositórios correspondentes.
